# CG-Fun-Week-1

🎉 **CG Fun Week 1 - Roda Undian Hias Roti Tubuh Kristus**

Aplikasi web interaktif roda undian (gacha / lucky wheel) bertema Neobrutalisme & Komik Pop untuk aktivitas kelompok gereja (Connect Group - CG Fun).

## 🌟 Fitur Utama
- **Roda Undian Interaktif (Spin the Wheel)**: Animasi putaran fisika dengan perhentian acak dan efek audio.
- **10 Tema Anggota Tubuh Kristus**:
  1. Telinga - Mendengar Firman & Sesama
  2. Mata - Memandang dengan Kasih
  3. Mulut - Memberitakan Kabar Baik
  4. Hati - Kasih Kristus yang Lembut
  5. Tangan Terbuka - Melayani & Menyambut
  6. Kaki - Membawa Kabar Damai
  7. Pundak - Saling Menopang di CG
  8. Kepala / Mahkota - Kristus Sang Pemimpin
  9. Lingkaran Tubuh - Komunitas yang Sehati
  10. Ranting Berbuah - Menghasilkan Jiwa Baru
- **Kartu Hasil & Panduan Menghias Roti**: Dilengkapi ayat Alkitab, makna rohani, dan panduan praktis menghias roti.
- **Download Kartu HD (PNG)**: Render langsung di canvas client-side dengan gambar teroptimasi.
- **Efek Konfeti & Pop-Up**: Desain visual neobrutalisme yang ceria dan penuh warna.

## 🚀 Teknologi
- HTML5 & Vanilla JavaScript
- Tailwind CSS (CDN)
- Canvas Confetti
- Google Fonts (Bangers, Fredoka, Plus Jakarta Sans)

## 🌐 Deployment
Aplikasi ini di-deploy menggunakan **Vercel**.
